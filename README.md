# CS50x-Scratch-Game-Maze
# لعبة المتاهة والمطاردة - CS50x Week 0
هذا هو مشروعي الأول في كورس CS50 من جامعة هارفارد، وهو عبارة عن لعبة متاهة تم تصميمها باستخدام Scratch.

## شروط المشروع المطبقة:
* شخصيات متعددة (فأر، قطة، تفاحة).
* بلوك مخصص بمدخلات (Custom Block with Input) للتحكم في حركة الارتداد.
* عداد نقاط (Score Variable) وحلقات تكرارية وشروط برمجية متكاملة.
